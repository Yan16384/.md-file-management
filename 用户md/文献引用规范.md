# 文献引用规范

适用于采用顺序编码制的论文、研究报告等 Word
文档。**只调整正文引文及文末参考文献；正文其他文字和排版保持不变。**
用户或学校提供明确的正式模板时，以正式模板为准。最终目标是：正文引文按首次出现顺序统一编号为
`[1]` 至 `[xx]`，每个引用标记（包括方括号）整体上标，并确保编号、作者身份、文献实际内容与正文叙述相符。

## 1. 修改边界

- **正文内容与排版保持不变**：保留引用标记以外的全部文字、字体、字号、行距、缩进、对齐和段落结构；不新增引号、空行或手动换行。仅调整引文编号、引用关联及引文标记格式。若发现正文观点与文献不符，不得擅自改写正文，应在单独的核验结果中说明。
- **文献原文不动**：允许调整条目编号、移动完整条目，不得擅自修改作者、题名、期刊、年份、卷期、页码等著录信息。作者名前已有的数字（如
  `1G. Zhang`、`3Z. Xuefu`）必须保留，不得误当作待删除的条目编号。
- **修改前建立完整对应表**：从原文件逐一记录"原方括号编号---完整文献条目---正文所有引用位置---该处引用所支持的具体陈述"；已有
  Word
  交叉引用还须核对实际指向。不得按文末排列位置、作者名前数字或编号外观猜测文献身份。
- **先核实身份，再重排编号**：按正文中每篇不同文献首次出现的顺序重新编号为
  `[1]`、`[2]`......`[xx]`。同一文献重复引用沿用同一编号，正文编号与文末完整文献条目同步调整。不能只改正文数字而不移动或更新对应的完整条目。
- **区分重复文献与相似文献**：相同作者不代表同一篇文献。须结合作者、题名、年份、期刊或学校、卷期、页码等信息核实。只有确认是同一篇文献后才能合并；同一篇文献即使标点、空格或著录格式存在差异，也应结合完整信息识别为重复项；作者相同但题名或出版信息不同的文献不得仅凭作者相同合并。身份不明或著录信息冲突时，应记录问题，不得自行拼接、改写或猜测。
- **防止编号错配**：例如原 `[6]` 对应 `3Z. Xuefu`，调整为新 `[3]`
  后仍必须对应同一篇 `3Z. Xuefu` 文献，不能变成
  `6D. Adam`。原始编号重复、缺失或对应关系无法确认时，列明问题，不得猜测修改。
- **扫描所有可能的引用形式**：检查全文中的方括号编号、Word
  交叉引用、裸上标数字及其他疑似引用形式，包括正文段落、表格、图题、注释和脚注。裸上标数字必须结合上下文和文末条目确认身份，不能把普通数字、年份、公式编号、图表编号或其他非引用数字误判为文献引用；也不能因为引用没有采用标准方括号格式就直接遗漏。
- **修订记录处理**：修订记录可能影响正文当前显示内容的提取。核对时应明确以哪种视图作为当前正文依据，并保留原有修订记录；不得将删除修订中的旧引文误算为当前有效引用，也不得为清理引用而擅自接受或拒绝修订。
- **无法确认时不得猜测修改**：原始编号重复、缺失、文献身份无法确认、正文观点与文献支持关系不明或原文不可获取时，应保留正文原文，并在单独的核验结果中列出具体位置、原编号、问题和待确认事项。不得将未经核实的内容标为"核实无误"。

## 2. Word 交叉引用与上标

- **文末参考文献使用 Word 自动编号列表**：编号显示为
  `[1]`、`[2]`......，不得手工输入编号。完成文献重排后，正文通过"**交叉引用
  → 编号项 → 段落编号**"插入指向对应条目的真实 **REF
  域**，并启用超链接；不得用普通文本或普通超链接冒充真实交叉引用。
- **正文引用必须关联到正确条目**：重复引用必须指向同一条文献；多篇合引中的每个编号均须分别关联到各自正确的参考文献。交叉引用工具不会自动判断文献身份，也不会自动按照正文首次引用顺序排列文末条目，必须先核实对应关系，再进行编号和关联。
- **正文引文统一采用方括号加阿拉伯数字**：编号按正文中每篇文献首次出现的顺序连续排列为
  `[1]` 至 `[xx]`，不得跳号、重号或遗漏。同一文献重复引用始终使用同一编号。
- **整个引用标记整体上标**：左方括号、全部数字和右方括号必须整体上标；若引用标记中包含逗号、连接号等合引符号，也应统一按标记整体处理。引用标记字体统一为
  **Times New
  Roman**，不加粗。不得只将数字上标而遗漏方括号，也不得改变相邻正文的字体、粗细或位置。若
  Word 将同一引用标记拆分为多个文本片段，必须逐片段检查并统一格式。
- **文末编号不上标**：参考文献列表中的编号保持正常字号、正常位置，不上标。正文引文和文末编号的格式要求不得混淆。
- **核对自动编号的真实结果**：对于 Word
  自动编号列表，必须读取并检查编号列表实际显示的编号结果及列表重启设置，不能仅按段落顺序推测条目编号。更新全部引用域后，再检查编号显示结果、REF
  域、目标书签和超链接目标。
- **真实域与格式都要核验**：REF
  域存在、超链接可以点击、编号连续或外观正常，都不能单独证明引用身份正确。必须进一步核对每个
  REF 域指向的目标书签和完整文献条目，并与修改前建立的对应表逐一比对。

## 3. 后置参考文献格式

- **后置部分的位置与顺序**：总结与展望、附录、致谢使用相应的后置标题和正文样式。参考文献集中置于文档后部，不按章节分别列出；"参考文献"标题采用后置标题样式，并另起新页。

- **参考文献标题格式**："参考文献"标题采用黑体 **16
  pt**、加粗、段落居中、**1.5
  倍行距**。必须设置并核验标题所在段落的对齐和行距属性，不能只修改文字字体或套用样式后就默认格式正确。

- **文献条目格式**：中文宋体，英文及数字 Times New Roman，**12 pt、1.5
  倍行距**；悬挂缩进约 **0.74 cm**，续行与作者文字起始位置对齐。按
  `[1]`、`[2]`......连续编号，文末编号不上标。标点与文献类型标识应统一。仅调整编号和关联时，不擅自改写原著录内容。

- **普通论文、研究报告的英文期刊作者**：不超过 3 人时全部列出；超过 3
  人时列前 3 人，再加 `et al.`。

- **学术论文或学位论文的参考文献表**：另起新页，标题沿用后置部分标题样式；条目采用与参考文献相同的编号和著录格式，中文宋体、英文及数字
  Times New Roman，12 pt、1.5 倍行距及约 0.74 cm
  悬挂缩进。**该部分英文期刊论文作者必须全部列出，不使用
  `et al.`**；此规则优先于普通论文、研究报告的作者省略规则。用户或学校提供的正式模板另有明确要求时，以正式模板为准。

- **常见文献类型的著录示例**：

  | 类型 | 原有示例结构 |
  |---|---|
  | 英文期刊 | `[1] Author A, Author B, Author C, et al. Title [J]. Journal, Year, Volume: Pages.` |
  | 中文期刊 | `[2] 作者1, 作者2. 论文题目 [J]. 期刊名. 年, 卷: 起止页码.` |
  | 专利 | `[3] 作者. 专利名称: 专利号 [P]. 日期.` |
  | 著作 | `[4] 作者. 书名 [M]. 出版地: 出版社, 年.` |
  | 译著 | `[5] 作者. 书名 [M]. 译者译. 出版地: 出版社, 年.` |
  | 学位论文 | `[6] 作者. 论文题目 [博士论文/硕士论文]. 城市: 学校, 年.` |

- **模板优先**：未经用户或学院明确要求，不把学校提供的文献示例改成另一套引用标准；用户或学校提供正式模板时，以正式模板为准。

## 4. 验收

- **编号与完整对应关系**：逐一核对正文所有引用位置和文末所有文献条目，确认正文引文已按首次出现顺序整理为连续的
  `[1]` 至 `[xx]`，无跳号、重号、漏号或错号；同一文献重复引用编号一致，正文每个编号均对应唯一正确的文献，文末每条文献也都已核查其正文引用情况。不得只检查编号是否连续。
- **核对段落中的人名与文献作者**：逐处检查引文所在句段提到的人名、作者或研究团队，与对应参考文献的作者信息是否相符。若正文是在转述综述中提及的其他学者观点，不能仅因正文人名与参考文献第一作者不同就直接判错；必须结合上下文和文献实际内容确认该文献确实讨论或支持了该观点。
- **核对正文叙述与文献实际内容**：不能只看编号、作者姓名或题名。应依据可获取的原文、摘要、研究方法、数据和结论，检查文献是否确实支持引用段落中的具体观点、数据、方法或结论；同时检查是否存在张冠李戴、把其他文献的结果误归给该作者、夸大文献结论、将相关性写成因果关系等问题。多篇合引必须逐篇核实每篇文献实际支持的内容。
- **核验引用形式与 Word
  关联**：确认全文可能的引用形式均已检查，包括方括号引用、裸上标数字和表格、图题、注释、脚注中的引用；核对正文
  REF
  域、目标书签与完整文献条目，确认自动编号、超链接和跳转目标正确。不能以抽查、题名相似、作者姓名相同或
  REF 域存在代替逐处核验。
- **核验全部格式属性**：检查正文引用标记的方括号和数字是否整体上标、字体是否为
  Times New
  Roman、是否未加粗，以及相邻正文格式是否保持不变；检查文末编号是否不上标。另须核验"参考文献"标题的段落居中、字体字号、加粗和
  1.5
  倍行距，以及文献条目的字体、字号、行距、悬挂缩进和自动编号的实际显示结果。
- **保存后重新检查**：保存文档后关闭并重新打开，更新全部引用域，再次检查编号、引用对应关系、超链接目标和上标状态，并渲染检查页面显示。只检查代表性位置或页面外观不足以验收。
- **单独提交核验结果**：核验说明放在 Word
  正文之外，不得插入正文或破坏原有排版。简要列出已修正的问题，以及所有无法确认的引用位置、原编号、具体原因和待处理事项。**编号连续、显示正常、作者姓名相同、题名相似或
  REF 域存在，均不等于验收通过。**
