# 毕业论文格式 — 内蒙古大学专业学位硕士论文

仅用于内蒙古大学专业学位硕士论文，或用户明确指定该校 2025 年修订模板的 Word。参数来自用户原有规范记录；实际正式模板不同则以模板和当次要求为准，不冒称已核验校方原文。其他 Word 不套用学校封面、声明、页眉、页码和双语题注。

## 1. 执行范围与结构

- 纯排版保留正文、数据、公式、引用、图表内容和章节结构，采用 Word 样式、编号和域。
- 格式优先级：用户最新要求 → 正式学校模板 → 现有论文统一格式。公式、脚注、横向页面、四级标题等未明确项目不臆造学校规定；仍无法确定时询问用户。
- 论文顺序：封面 → 原创性声明 → 在学期间研究成果使用承诺书 → 中文题目/摘要/关键词 → 英文题目/ABSTRACT/Keywords → 目录 → 第一章绪论 → 后续研究章节 → 总结与展望 → 参考文献 → 附录 → 致谢 → 攻读学位期间发表的学术论文目录。主要部分按模板另起新页。

## 2. 页面、页眉和页码

| 项目 | 参数 |
|---|---|
| 纸张 | A4，21.0 × 29.7 cm |
| 页边距 | 上 2.0 cm、下 2.7 cm、左/右各 2.0 cm |
| 正文页眉/页脚距边界 | 约 1.5 cm / 2.0 cm，以正式模板为准 |
| 页眉 | 中文摘要至末尾：居中“内蒙古大学硕士学位论文”，下方单实线；封面及声明页无页眉 |
| 页眉字号 | 原记录约 9 pt；原记录“五号”与该数值不一致，须按正式模板核对 |
| 页码 | PAGE 域，底部居中，约 9 pt |
| 前置页 | 封面及两份声明不显示页码；中文摘要至目录用大写罗马数字 I、II、III… |
| 正文页 | 第一章起重新从阿拉伯数字 1 编号；分节符控制两套页码 |

保留模板的特殊分节与版心，不擅自重排。

## 3. 共用文字样式

| 样式 | 格式 |
|---|---|
| 中文正文 | 宋体、小四 12 pt、1.5 倍行距、两端对齐、首行缩进 2 个中文字符（模板约 0.85 cm），正常段前段后无额外空白 |
| 英文及数字 | Times New Roman；字号、行距随所在文字 |
| 一级章标题 | 黑体 16 pt、居中、1.5 倍行距、段前/后约各 0.25 行、不首行缩进，每章另起新页 |
| 二级标题 | 黑体 14 pt、左对齐、1.5 倍行距、段前/后各 0.25 行、不首行缩进 |
| 三级标题 | 黑体 12 pt，其余同二级标题 |
| 后置部分标题 | 黑体 16 pt、加粗、居中、1.5 倍行距、段前/后约各 0.25 行；总结与展望、参考文献、附录、致谢及学术论文目录各另起新页 |
| 中文题注 | 楷体、五号 10.5 pt、居中、1.5 倍行距 |
| 英文题注 | Times New Roman、10.5 pt、居中、1.5 倍行距，末尾英文句点 |

章标题编号统一为“第一章”“1.1”“1.1.1”。学校附件未规定四级及以下标题，除原有结构或明确要求外不新增。第二章及后续研究章按结构设置“本章小结”（如 2.5），用二级标题样式，小结正文用正文样式。

## 4. 封面、声明和摘要

### 封面与声明

- 保留学校标准封面、校名标识、横线和字段位置。字段包括学校代码 **10126**、学号、分类号、编号、“硕士学位论文”“（专业学位）”、题目、作者、学科专业、研究方向、指导教师、合作导师、培养单位和日期。
- 封面题目：黑体、加粗、小一 24 pt、固定行距 36 磅、居中；其余文字严格沿用模板。
- 原创性声明和在学期间研究成果使用承诺书保留学校原文及基本版式；标题宋体约 16 pt、居中，保留作者/导师签名和日期。

### 中文摘要

独立起页，按“中文论文题目 → 摘要 → 摘要正文 → 关键词”排列。

- 中文题目与“摘  要”：黑体、16 pt、加粗、居中、1.5 倍行距；摘要标题段前/后按模板约各 0.25 行。
- 摘要正文使用正文样式。
- 关键词：12 pt、1.5 倍行距，格式 `关键词：关键词1；关键词2；关键词3`，中文分号分隔。

### 英文摘要

紧随中文摘要按模板独立排版，按“英文题目 → ABSTRACT → 摘要正文 → Keywords”排列。

- 英文题目约 16 pt，ABSTRACT 16 pt；均 Times New Roman、加粗、居中、1.5 倍行距。
- 正文和 Keywords：Times New Roman、12 pt、1.5 倍行距。
- 格式 `Keywords: keyword 1; keyword 2; keyword 3`，英文分号分隔。

## 5. 目录、图表和自动引用

### 论文目录

独立起页；“目  录”黑体 16 pt、居中、1.5 倍行距。用 TOC 自动目录域，页码与实际页面对应。包含摘要、ABSTRACT、各章及二/三级标题、总结与展望、参考文献、附录、致谢、学术论文目录；目录是否列入自身按实际学校模板处理，避免自引用。

### 图表

- 图片和表格居中、不超版心；按章连续编号，如图 1.1、表 2.1。
- 图片排列：图片 → 中文图题 → 英文图题；英文形式 `Fig. 1.1 XXXXX.`。
- 表格排列：中文表题 → 英文表题 → 表格；英文形式 `Table 1.1 XXXXX.`。题注按第 3 节样式。
- 使用真实 Word 三线表：顶/底各 **1.5 磅**，表头分隔线 **1 磅**，无竖线、内部横线。表注如有置于表下，字体沿用模板。
- 跨页重复真正的表头，防止断裂、遮挡或超出版心。仅输出表格文本时用 Markdown 或制表符，便于转成 Word 表格。

### 自动化结构

标题样式与多级列表控制大纲/编号；TOC、Caption/SEQ、PAGE 域控制目录、题注和页码；正文图表引用尽量用交叉引用。修改后更新域、目录和编号；不用空格模拟居中、手工页码或大量回车分页。

## 6. 后置部分与参考文献

总结与展望、附录、致谢使用后置标题和正文样式。参考文献集中置于后部，不分章列出；标题用后置标题样式。

- 文献正文：中文宋体、英文 Times New Roman、12 pt、1.5 倍行距，按 `[1]、[2]…` 编号，悬挂缩进按模板约 **0.74 cm**；标点和类型标识统一。
- 英文期刊作者不超过 3 人时全列；超过 3 人列前 3 人加 `et al.`。
- 学术论文目录另起新页，标题同后置标题；条目 12 pt、1.5 倍行距、中宋体/英 Times New Roman，编号和格式参考文献。**该部分英文论文作者必须全列，不用 et al.。**
- 未经用户或学院要求，不把学校文献示例改成另一套引用标准。

| 类型 | 原有示例结构 |
|---|---|
| 英文期刊 | `[1] Author A, Author B, Author C, et al. Title [J]. Journal, Year, Volume: Pages.` |
| 中文期刊 | `[2] 作者1, 作者2. 论文题目 [J]. 期刊名. 年, 卷: 起止页码.` |
| 专利 | `[3] 作者. 专利名称: 专利号 [P]. 日期.` |
| 著作 | `[4] 作者. 书名 [M]. 出版地: 出版社, 年.` |
| 译著 | `[5] 作者. 书名 [M]. 译者译. 出版地: 出版社, 年.` |
| 学位论文 | `[6] 作者. 论文题目 [博士论文/硕士论文]. 城市: 学校. 年.` |

## 7. 检查与交付

1. 核对本次涉及的页面、页眉页码、正文/标题样式、分节、目录、章编号、图表范围及双语题注、三线表、文献作者与后置部分起页要求。
2. 纯格式修改验证文字节点和段落数不变、OOXML 合法、目标格式达标；只有无分页风险时可免完整渲染。
3. 涉及分页、图表、题注、页眉页码、目录、跨页表格或用户要求时，执行整篇实际分页/渲染检查，排除孤立标题、乱码、空行、遮挡和表格断裂。
4. 修复后重新核查受影响部分，确认交付的是已验证文件，正文数据未误改。完整 Word 的内容验收依任务路由执行，不因本文件的局部排版检查省略适用的整篇验收。
