## 1. 文件职责

| 文件 | 作用 |
|---|---|
| `AGENTS.md` | 全局规则、任务路由、软件经验、发布和本机下载流程 |
| `用户md/去ai规范.md` | 正式写作、技术中文、通用 Word 格式与成品验收 |

| `SHA256SUMS.txt` | AGENTS 和四份专项规范的原始字节校验值 |

专项规范按不同场景独立维护。要求不同不等于冲突；优化只处理单个文件内部的冗余、失效引用和同一适用条件的矛盾，保留参数、例外及场景差异，不合并成同一套要求。每份 Markdown 包含可点击目录。

## 2. 读取与本机使用

- 本机 AGENTS 是云端下载副本，供 Codex 加载；不再以本机为修改源覆盖云端。
- 专项规范通过已登录的 `gh api` 从准确路径读取，不长期落盘。需要网络与有效认证；读取失败时停止依赖该文件的步骤并报告。
- 规范的详细触发条件见 AGENTS 第 2 节；同一任务可以命中多份规范，各自负责适用部分。
- 下载更新不保证进行中的会话自动重载；必要时开启新会话。

## 3. 更新、发布与下载

用户明确要求固化经验、更新或同步规则时，按 AGENTS 第 4 节执行：从云端当前提交准备临时副本 → 按职责修改并验证 → 更新唯一的根目录 README 和 SHA-256 清单 → 逐文件提交 `main` → 创建 tag 和 Release → 回读核验 → 下载该提交的 AGENTS 到本机并校验 → 清理本次临时副本。

所有规则先在云端发布，再下载本机 AGENTS；专项规范始终留在云端。本机未发布差异须先审阅合并，不能静默覆盖云端版本。

## 4. 版本与恢复

当前版本：**v1.0.3**。本次精简文件内部冗余、为所有 Markdown 添加目录，并将全局 AGENTS 的权威来源改为云端。

常规发布递增补丁号，保留历史 tag/Release。新版本不上传自制压缩包；GitHub 自动提供的源码 zip/tar.gz 是平台功能。根目录只有一个 README，其下方预览是同一文件。

需要恢复时选择对应 tag 并核对 `SHA256SUMS.txt`。正常使用只下载 AGENTS；专项规范的回退应明确发布到云端，不用恢复本地用户md目录。

## 5. 验证与安全

保持仓库 PRIVATE，不上传凭证明文、会话、缓存或数据库。提交禁止强推；发布后确认 main/tag/Release 对应正确提交、文件集合和清单一致、Release 无自定义附件。本机 AGENTS 必须与已核验的云端文件字节一致。
